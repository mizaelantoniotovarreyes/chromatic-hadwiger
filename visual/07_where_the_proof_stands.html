The Honest Status

Where the Proof Stands

χ(G) = 1 + p(G)  ·  adjacency ✓  ·  connectivity = open

What is proved, what the construction always maintains, and exactly where the gap is — stated plainly, with no overclaim.

✅ Proved Theorem

  • The identity χ(G) = 1 + p(G) for every connected simple graph (palette-expansion number). Short, self-contained proof.
  • The Patio Adjacency Lemma: in an optimal palette-expansion coloring with expansion centers c₁,…,cₖ, each center cⱼ has a neighbor in every earlier color class Aᵢ. Consequently every pair of color classes is joined by a direct edge.
  • Verified computationally on 130,000+ graphs across k ∈ {3,4,5,6,7} — 0 failures.
In plain words: if you color a graph with as few colors as possible the smart way, the color groups are always pairwise touching. That part is fully nailed down — by hand and by computer.

✅ What the construction always maintains Unconditional

  • Disjointness of the branch sets.
  • The adjacency invariant — pairwise adjacency, free at initialization and preserved by every legal move.
  • Bounded repair: a strictly decreasing connectivity potential caps the number of repair moves at |V(G)| − k, so the process always terminates.
In plain words: the building process never breaks the “everyone touches everyone” rule and never runs forever. Those guarantees are real and proved.

⚠️ Open — the exact gap Open Problem 6.1

  • Branch-set connectivity is NOT guaranteed. Making each branch set internally connected while preserving adjacency is the open question.
  • Phrased as a move: does an adjacency-preserving connectivity move always exist while some branch set is disconnected? The answer is not known.
  • This is exactly Hadwiger’s conjecture for the relevant k — and it is open for k ≥ 7 (settled for k ≤ 6 by Hadwiger; Wagner; Robertson–Seymour–Thomas).
  • Computational evidence is reported for the adjacency half only: on 562 tested graphs the contracted graph was Kₖ-complete (every pair adjacent), but the branch sets were internally connected in only a minority. We do not report these as Kₖ-minor certificates.

In plain words: we can always make the groups touch, but we cannot yet guarantee each group is a single connected piece. Closing that gap would prove Hadwiger — and nobody has, for 83 years. This work does not claim to.

🔭 The honest bottom line No overclaim

  • This work contributes a clean, independently-proved structural lemma and an honestly-bounded construction — plus a precisely formulated open problem equivalent to Hadwiger.
  • We make no claim about Hadwiger’s conjecture for k ≥ 7.
  • A companion line of work (the Flip Conjecture, a relaxed move set) explores the same gap from a new finite/local angle — it implies Hadwiger, so it is at least as hard, and it is itself unproved in general. It lives in its own project and is not claimed here.
