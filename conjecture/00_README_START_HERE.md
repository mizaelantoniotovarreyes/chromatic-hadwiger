## ✅ The honest status (one paragraph)

What is **proved:** the identity **χ(G) = 1 + p(G)** and the **Patio Adjacency Lemma**
(every pair of color classes is joined by an edge at an expansion center), verified on
130,000+ graphs with 0 failures.

What is **open:** making each branch set internally connected while preserving adjacency —
**Open Problem 6.1**, which is exactly **Hadwiger's conjecture for k ≥ 7**. This work does
**not** claim to prove it.

The separate **Flip Conjecture** exploration is a *different* project and lives in its own
repository (`github.com/mizantorey/flip-conjecture`). **One paper = one idea.**
